# Task 2 — Veeam Backup & Replication Installation

## Objective

Install Veeam Backup & Replication on the `VEEAM01` server.

This server will be used as the main Veeam Backup & Replication server for the lab.

## Server

The Veeam server was prepared in Task 1.

- Hostname: `veeam01`
- OS: Windows Server 2022
- CPU: 8 vCPU
- RAM: 32 GB
- Internal IP: `10.10.20.3`

## Installation

The Veeam Backup & Replication installation ISO was downloaded from the official Veeam website.

The installation was performed on `VEEAM01`.

After the installation completed, the Veeam Backup & Replication console was opened successfully.

## Verification

The Veeam Backup & Replication console is running successfully on `VEEAM01`.

The main Veeam interface is available and ready for the next configuration tasks.

## Result

Veeam Backup & Replication was installed successfully on `VEEAM01`.

The server is ready for the next task: preparing the workload VM that will be protected by Veeam.
